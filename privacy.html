Privacy Policy

Last updated: October 18, 2026

Herm is a personal assistant application that runs locally on its owner's computer. It is used only by its owner and is not offered to the public. This policy explains how Herm handles data, including data obtained through Google APIs.

Data Herm accesses

With the owner's explicit consent through Google's OAuth sign-in, Herm may access:

  • Gmail: message content, headers, labels, and drafts, in order to read, search, summarize, draft, and send email when the owner asks.
  • Google Calendar: calendars and events, in order to view, create, and update events when the owner asks.
  • Basic profile: the account's email address, to identify which account is connected.

How data is used

Google user data is used solely to provide the features the owner requests. Requests are processed on the owner's own computer by a locally hosted language model. Herm does not use Google user data for advertising, profiling, or training AI or machine-learning models.

Storage and security

OAuth tokens and any temporarily cached data are stored only on the owner's local computer. No Google user data is stored on external servers operated by Herm. Data is kept only as long as needed to complete a request.

Sharing

Herm does not sell, rent, share, or transfer Google user data to any third party, except as needed to carry out an action the owner explicitly requests (for example, sending an email the owner asked to send) or as required by law.

Google API Services User Data Policy

Herm's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party apps & services. Revoking access stops Herm from reading any further data, and locally stored tokens can be deleted from the owner's computer.

Changes

This policy may be updated from time to time. The date above reflects the latest revision.
